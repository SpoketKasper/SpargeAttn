This is a fork of SpargeAttn for use in the project ClusterAttention. It adds LSE-return, initializations for attention output and LSE (from a disjoint attention computation), and masking of keys that is uniform over the queries in a block. The top-level callers are unchanged from the original repo, with the exception of an added return_lse parameter to some. Some call paths may be broken, as we have only ensured that those used in ClusterAttention are functional. For access to the initalizations and masking, call the lower-level function `qattn.qk_int8_sv_f8_accum_f32_block_sparse_attn_inst_buf_fuse_v_scale_sm90`. The caller used for this in ClusterAttention may be added in the future.
